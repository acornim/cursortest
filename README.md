# 학생-교사 웹 애플리케이션

Next.js, TypeScript, Tailwind CSS를 사용한 현대적인 웹 애플리케이션입니다.

## 시작하기

먼저 종속성을 설치하세요:

```bash
npm install
```

개발 서버를 실행하세요:

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 결과를 확인하세요.

## 프로젝트 구조

- `/app` - Next.js App Router 페이지 및 레이아웃
- `/app/student` - 학생용 페이지
- `/app/teacher` - 교사용 페이지
- `/components` - 재사용 가능한 React 컴포넌트

## 기술 스택

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Package Manager**: npm
